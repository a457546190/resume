GameArClient · 2D 回合制手游 Demo

个人项目｜持续开发

面向 Android 的小型二次元回合制 RPG Demo，重点实践移动端 Unity 客户端架构、UI、资源加载、网络通信与完整联调流程；服务端仅作为客户端闭环的配套实现。

Unity 6.3 LTS C# UI Toolkit UniTask Addressables MagicOnion MessagePack Android / IL2CPP
  • 客户端架构：按 Boot → Login → Main → Battle 组织场景与初始化流程，以 AppBootstrap 管理跨场景核心对象，并拆分 Session、网络封装与 Feature 业务层。
  • UI 与资源：从 UGUI 重构至 UI Toolkit，使用 UXML / USS 构建页面；结合 SVG 资源与 Addressables 管理可异步加载内容，并处理页面生命周期、加载遮罩与资源释放。
  • 异步与网络：以 UniTask 组织异步流程；客户端通过 MagicOnion（gRPC / HTTP/2）与服务端通信，使用 JWT 会话、MessagePack DTO 与共享程序集降低通信层重复定义。
  • 服务端联调：为验证真实客户端链路，配套实现 ASP.NET Core + EF Core + PostgreSQL 服务，并部署至阿里云 Linux，通过 systemd 管理服务；掌握日志排查、数据库迁移及移动端远程联调。
  • 工程实践：完成 Windows x64 与 Android 构建测试，使用 Git / GitHub 管理版本；持续完善登录、资源、养成、背包及回合制战斗等最小可玩循环。
